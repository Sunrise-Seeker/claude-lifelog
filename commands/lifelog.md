# /lifelog — 手动立即记录一条日记

当用户输入 `/lifelog` 时，立即将用户提供的内容（或当前对话内容）写入日记。

## 使用场景

- 用户有一条东西想立刻记下来，不等到对话结束
- 用户想确认某件事已经被记录了

## 执行逻辑

1. **判断用户意图**

   | 用户说 | 执行 |
   |--------|------|
   | `/lifelog 今天面试结果出来了` | 判断类型 → 直接写入 |
   | `/lifelog` （无内容） | 问用户："想记什么？" |
   | `/lifelog --event ...` | 强制写入记事 |
   | `/lifelog --thought [主题] [内容]` | 强制写入想法 |
   | `/lifelog --state ...` | 强制写入心理状态 |

2. **自动判断类型**（无 `--` 标志时）

   - 描述行为/事件 → `lifelog_write_event(content)`
   - 表达看法/分析 → `lifelog_write_thought(topic, content)`（topic 从内容中提炼）
   - 描述情绪/感受 → `lifelog_write_state(content)`
   - 混合内容 → 分别调用多个工具

3. **回复**：告知用户写入了哪类，一句话即可，不要展开。

## 内容规范

- 第一人称，口语化，保留细节
- 不超过 150 字（更长的内容会被自动截断到 500 字）
- 不记录纯技术内容（代码、报错、API 文档）
